## vite 와 tsc

vite 는 ts 나 tsx 에서 esbuild 로 타입을 지우기만 한다.

tsc 가 타입이 맞는지 검사한다.

> 실제 사례
Board.tsx 에 const unused = 1; 을 선언한 뒤 noUnusedLocals 옵션을 켜두었지만, pnpm tsc --noEmit 은 실패한 반면 pnpm dev 는 그대로 떴다.
옵션은 tsc 를 실패시킬 뿐이고 tsc 호출이 발생하지 않으면 타입 검사도 일어나지 않는다.

검사 옵션을 켜는 것과 검사를 강제하는 것은 다른 일이다.

나중에 pnpm build 같은 빌드 스크립트에 tsc --noEmit 등을 포함시키거나 할 수 있다.
혹은, CI 나 pre-commit hook 에 달아줄 수도 있다.
