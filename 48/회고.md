## Rollback

롤백 방식을 채택할 때 주의할 점이 있다
롤백은 비정상 흐름이 발생했을 때 적극적으로 원상태로 복구를 시도하기 때문에,
비정상 흐름의 종류에 따라 원상 복구가 아닌 추가적인 처리가 필요하다면 예외 분기를 확실히 설정해야 한다


## error 대응 설계

error 대응 설계를 하기 위해서 가장 먼저 해야할 일은 어디서 어떤 error 가 발생하는지 관찰하고 유형화하는 것이다
저수준 api 나 라이브러리가 이미 결정해둔 error 에 대해서는 사용처에서 catch 해서 처리하면 되고,
서비스 맥락에 의해서 정의되는 비정상 흐름에 경우 알맞은 error 생애를 설계하고 대응시키면 된다
