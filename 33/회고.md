## useState

React 가 useState 를 추적 관리하는 과정
React 는 컴포넌트 함수가 호출되어 전개된 동적 스코프 내에서 직/간접적으로 호출된 useState 들을 해당 컴포넌트 소속으로 관리한다.
따라서 Board 입장에서 직계 하위 스코프에서 1회, usePosts() 스코프내에서 2회, 총 3회의 useState 호출을 한 셈.

## Rules of Hooks

hook 을 호출할 때에는 반드시 top-level 에서 호출해야만 함.
React 는 hook 을 component 내에서의 호출 순서에 의존해 식별하기 때문.
조건적 호출은 렌더마다 식별 관계가 일관되게 유지될 수 없게 만듦.

근데 hook 이 정확히 뭔지는 아직 잘 모르겠다. 그냥 use~ 를 포함한 함수를 말하는 건가?
-> React Hook 을 직/간접적으로 호출하는 함수를 지칭함.

## async await

async 함수를 await 없이 부르면 비동기 처리가 어떤식으로 동작하는지 궁금하다.
특정 스코프를 기준으로 비동기 작업 처리 대기 영역이 생기는지,
진짜 전역적 비동기 작업이 발생하여 이후 모든 동기/비동기적 실행문이 차례대로 병렬로 실행되는지 등등
-> 엔진이 Job queue 를 채우고 호스트가 queue 를 비워나간다.
    그 과정에서 마이크로/매크로 태스크의 실행 전략이 나뉜다.
    대기는 Promise 객체를 통해 이루어진다.
