## useEffect

useEffect 와 컴포넌트의 정보적 생명 주기에 대한 고찰을 했다.
여러 useEffect 가 선언되어 있을 때 교통정리하는 경험을 해보았다.
컴포넌트 마운트 시 useEffect 보다 먼저 조립되는 정보 영역에 공유 flag 를 만들어 useEffect 간의 실행 흐름을 통제할 수 있었다.

## Loading

data 를 불러오는 함수를 따로 정의하게 되니 컴포넌트 내부적으로 난잡하게 흩어져있던 로직들이 사라져서 좋았다.
이제 앞으로 컴포넌트는 각종 load 함수들이 뱉어주는 값이나 예외를 받아먹으면서 api 계층이 뱉어줄 것으로 기대되는 결과 인터페이스에 의존하여 조금 더 독립적으로 개발을 할 수 있게 되었다.
이러면 나중에 api 쪽과 컴포넌트 쪽 작업을 서로 다른 사람이 맡아서 하게 되어도 반환에 대한 인터페이스 정의만 잘 해놓으면 병렬 작업이 충분히 가능할 것 같다.
나중에 반환 인터페이스나 미들웨어도 만들어보고 싶다.
