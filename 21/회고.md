## React 와 key

key 는 안정성과 고유성을 모두 만족해야 함을 깨달았다.
React 가 관리하지 않는 DOM 고유의 상태 등과 React 내부 상태가 얽혀있을 때 문제가 발생함을 관찰할 수 있었다.

## JS shorthand property

{ content: content } === { content }
위와 같이 key, value 의 이름이 같을 경우 축약이 가능하다.

## lazy 초기화

useState 를 사용하면서 state 에 대한 초기화를 제공하고 싶다면 함수 자체를 인자로 넘기는 것을 고려해야 한다.
주요 조건으로는 초기값 계산이 무겁거나, 부작용이 있거나, 딱 한 번만 돌아야 할 때이다.
